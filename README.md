# IFS Cloud Guidelines

## Opis projektu

To repozytorium służy do przechowywania wytycznych i instrukcji dla rozwoju IFS Cloud.

## Zawartość

### copilot-instructions.md
Plik zawierający instrukcje i wytyczne dla GitHub Copilot dotyczące rozwoju aplikacji IFS Cloud. Obejmuje:
- Konwencje nazewnictwa
- Standardy kodowania
- Best practices dla PL/SQL i API
- Wytyczne bezpieczeństwa
- Zasady testowania

## Użycie

Instrukcje w tym repozytorium są przeznaczone dla programistów pracujących z IFS Cloud i mogą być wykorzystane przez GitHub Copilot do generowania kodu zgodnego ze standardami projektu.

## Rozwój

Aby dodać lub zaktualizować wytyczne, edytuj odpowiednie pliki markdown i twórz pull requesty do przeglądu.
